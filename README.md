# CodeAlpha Machine Learning Internship — All 4 Tasks

This repository contains complete implementations for all four CodeAlpha Machine Learning internship tasks.

## Projects

1. **CodeAlpha_CreditScoringModel** — classification-based creditworthiness prediction with feature engineering and Precision, Recall, F1 and ROC-AUC evaluation.
2. **CodeAlpha_EmotionRecognitionFromSpeech** — MFCC-based speech emotion recognition using a CNN + BiLSTM model with support for RAVDESS, TESS and EMO-DB.
3. **CodeAlpha_HandwrittenCharacterRecognition** — CNN-based handwritten digit/character recognition using MNIST or EMNIST Letters.
4. **CodeAlpha_DiseasePrediction** — structured medical-data disease prediction using the Breast Cancer Wisconsin dataset and Logistic Regression, SVM, Random Forest and XGBoost.

Each folder is self-contained with its own `README.md`, dependencies, training pipeline and Streamlit demo.

> Educational projects only. Credit and medical predictions must not be used for real lending or clinical decisions.
